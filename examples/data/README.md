# Synthetic example archives

These SLAB-MAT archives are deterministic documentation fixtures, not
physical measurements:

- `example_reference.mat` — synthetic broadband reference source.
- `example_sample_a.mat` — reference transmitted through a neutral-density
  sample with a mild spectral bias.
- `example_sample_b.mat` — a second synthetic sample for future pair
  analysis examples.

All files use a 380–730 nm grid with 10 nm spacing. Metadata is deliberately
neutral and contains no real operator, project, laboratory or device serial
number.
