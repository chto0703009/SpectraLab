# SpectraLab v0.4.0 — Foundation Release

SpectraLab v0.4.0 is the first official public release.

This release establishes the engineering foundation for reliable spectral measurements in MATLAB.

## Highlights

- Stable public MATLAB API
- Instrument-independent architecture
- Interactive Spotread measurement workflow
- Environment verification through `setup` and `startup`
- Structured SPL error handling
- Regression test suite
- Complete Documentation Pack
- Engineering and scientific responsibility statement

## Verification

The release process requires:

- passing regression tests,
- real instrument measurement verification,
- documentation review,
- release checklist approval.

## Motto

Measure once.
Save forever.
Verify always.
