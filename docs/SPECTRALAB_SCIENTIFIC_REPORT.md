# SpectraLab scientific report

The reviewed project-level scientific and architectural description is
published in the repository as:

`docs/scientific-reports/spectralab_spectral_measurement_analysis_and_provenance.pdf`

A concise three-page English introduction is published as:

`docs/spectralab_summary_spectral_measurement.pdf`

Generated working copies remain below `output/pdf/` and are not the stable
repository links used by README or GitHub About.

The report describes the accepted SpectraLab v1.0.1 scientific and archive
contract while identifying the reviewed source worktree as v1.0.2-dev. It
covers instrument acquisition, ArgyllCMS Spotread, archive identity, spectral
processing, registered analyses, reports, ColorChecker sessions, provenance,
base-MATLAB policy, limitations and the Camera-41 hand-off.

The ReportLab authoring source used for this documentation copy is retained at
`tmp/pdfs/create_spectralab_scientific_report.py`. Scientific package reports
remain generated by SpectraLab's base-MATLAB report backend; this project-level
architecture report does not change that runtime policy.
